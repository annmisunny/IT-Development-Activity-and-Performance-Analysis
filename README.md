IT Development Activity and Performance Analysis

Project Overview

This project uses Microsoft Power BI to analyze IT development activities and evaluate developer productivity, workload, burnout patterns, and project performance. The dashboard transforms data into interactive visualizations to help identify trends and support data-driven decision-making.

Dashboard Pages

- Overview: Summarizes development activities, team performance, and productivity.
- Developer Performance: Compares developer productivity, work hours, and completion rates.
- Workload and Burnout Analysis: Examines working hours, burnout cases by team, and productivity in relation to burnout rates.
- Project Performance Analysis: Evaluates project activity, completion rates, and productivity.

Tools and Skills

- Microsoft Excel
- Data modeling and star schema
- DAX measures
- Data visualization
- Interactive slicers and filters
- Performance analysis

Project Files

- Power BI dashboard (".pbix")

Objective

To turn development activity data into meaningful insights that help compare performance, understand workload, and evaluate project outcomes.
